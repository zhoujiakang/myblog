跟着力扣官方的 Hot 100 题单刷：每天一道，按专题分组推进，不东一榔头西一棒子。

## 专题顺序

哈希 → 双指针 → 滑动窗口 → 普通数组 → 栈 → 二分查找 → 链表 → 二叉树 → 堆 → 贪心 → 回溯 → 动态规划 → 图论 → 技巧

同一专题连着刷，反复调用同一类套路；一个专题刷完做个小结再进下一个。

## 每题记录三件事

- 思路：怎么想到的，暴力解和最优解的差距
- 复杂度：时间与空间
- 卡点：卡在哪一步、为什么没想到

攒够数量后按专题整理成文章。
